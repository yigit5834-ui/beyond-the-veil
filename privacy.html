Privacy Policy

Last updated: November 15, 2026

This policy describes how Beyond the Veil Tools (the "Tool") handles data. The Tool is a private application used only by the owner of the YouTube channel Beyond the Veil to manage that channel. It is not available to the public.

What data the Tool accesses

When the channel owner signs in with Google, the Tool may access, for the owner's own YouTube channel only:

  • video uploads: the owner's own, original videos are uploaded to the owner's channel;
  • channel and video information (titles, descriptions, tags, thumbnails, privacy settings);
  • captions and translated titles and descriptions;
  • comments on the channel's videos, in order to read and reply to them;
  • channel statistics from the YouTube Analytics API (views, watch time, traffic sources, audience retention).

How the data is used

The data is used solely to manage and improve the owner's own channel: uploading videos, captions and translations, updating video details, replying to comments, and reviewing performance. It is not used for advertising, not sold, and not shared with any third party.

Storage

The Google sign-in token is stored only on the channel owner's personal computer. The Tool has no server and no database, and it does not collect data about other YouTube users beyond the public comments left on the channel's own videos. Statistics and comments read through the API are shown on screen when requested and are not kept: any copy saved on the owner's computer is refreshed or deleted within 30 days.

Google API Services

The Tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. See also the Google Privacy Policy. The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the locally stored token removes all stored credentials.
